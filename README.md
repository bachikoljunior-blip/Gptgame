# 声打（こえだ）

声で日本語のお題を読み、制限時間内の速さ・正確さ・コンボを競うブラウザゲームです。

## 遊び方

1. 音声入力またはキー練習を選びます。
2. 30・60・90秒、難易度3段階からコースを選びます。
3. 表示されたお題を読み、認識されると次のお題へ進みます。

スコア、文字／分、正確率、最大コンボを集計します。コース別の上位10件はブラウザの `localStorage` に保存されます。サーバーランキングやログイン機能はありません。

## 音声入力

Web Speech API の `SpeechRecognition` / `webkitSpeechRecognition` を使用します。音声認識はブラウザ、OS、地域、回線に依存します。Chrome系ブラウザを推奨します。音声がブラウザ提供者の認識サービスへ送られる場合があるため、個人情報や機密情報は読み上げないでください。

アプリ自身は録音データや認識文章を保存・送信しません。マイクはゲーム開始時だけ要求し、ゲーム終了時に停止します。

## ローカル起動

静的ファイル1枚なので、リポジトリのルートをHTTP配信してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。音声入力にはHTTPSまたはlocalhostが必要です。
