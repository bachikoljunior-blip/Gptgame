# 声打（こえだ）

日本語のお題を声で読み、制限時間内の回答速度と正確さを競うブラウザゲームです。

## 操作

1. 30・60・90秒と難易度を選び、「ゲーム画面へ」を押します。
2. 大きなマイクボタンを押すと聞き取りとゲーム時間が始まります。
3. 読み終わったら同じマイクボタンをもう一度押して回答を確定します。
4. 言い間違い・読み飛ばし・余計な言葉も含め、回答全体の正確率と得点を計算します。

問題ごとの時間制限とスキップはありません。「入力を消去」は聞き取り欄の端に分離してあり、確認画面なしで認識途中の入力だけを消します。ゲーム時間、得点、コンボ、お題は変えません。

## お題数

- やさしい: 75問
- ふつう: 75問
- むずかしい: 60問

以前の15・15・12問から、それぞれ5倍です。

## 読みと採点

音声認識が返す最大5候補を、それぞれ内蔵辞書でひらがな読みに変換します。お題の読みとの編集距離を計算し、最も近い候補を採用します。漢字・カタカナ・数字表記が違っても読みが同じなら同じ回答として扱います。正確率は全回答の挿入・削除・置換を累積して計算します。

## 音声入力

Web Speech API の `SpeechRecognition` / `webkitSpeechRecognition` を使用します。Chrome系ブラウザ推奨です。音声がブラウザ提供者の認識サービスへ送られる場合があるため、個人情報や機密情報は読み上げないでください。アプリ自身は録音データや認識文章を送信・保存しません。

## ローカル起動

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。
