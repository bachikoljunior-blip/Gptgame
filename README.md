# 声打（こえだ）

日本語のお題を声で読み、制限時間内の速度と正確さを競うブラウザゲームです。

## 操作

1. 30・60・90秒と難易度を選び、「マイクを許可して開始」を押します。
2. ゲーム開始時にマイク許可を求め、許可後は1問目の聞き取りが自動で始まります。
3. 問題が切り替わるたびにマイクは自動でオンになります。
4. 読み終わったら大きな「回答を確定」ボタンを押します。
5. 回答を確定するとすぐ次の問題へ進み、マイクも自動でオンになります。直前の採点結果と間違えたひらがなは、次の問題中も下部に残ります。

問題ごとの時間制限とスキップはありません。「入力を消去」は認識結果欄の端に分離し、確認画面なしで認識途中の入力だけを消します。ゲーム時間、得点、コンボ、お題は変えません。

## お題数

- やさしい: 150問
- ふつう: 150問
- むずかしい: 120問

元の15・15・12問から、各モードの文章バリエーションを10倍にしています。

## 読みと採点

音声認識が返す最大5候補を、それぞれ内蔵の読みデータでひらがなへ変換します。お題のひらがな読みと編集距離で比較し、最も近い候補を採用します。漢字・カタカナ・数字表記が違っても、読みが同じなら同じ回答として扱います。

回答結果では次のように差分を表示します。

- 緑: 正しく読めたひらがな
- 赤: 言い違えたひらがな
- 黄: 読み飛ばした、または余分に読んだひらがな

正確率は全回答のひらがな単位の一致数から計算します。速度は、正しく読めたひらがなの数を実際のゲーム時間で割った「ひらがな/分」です。採点後もゲーム時間を止めず、すぐ次のお題へ進みます。

## 画面

ゲーム中はヘッダーとフッターを隠し、画面の高さに合わせて問題文、認識結果、回答ボタン、差分結果を配置します。375×667、360×640、390×844、768×700、1440×900で、ページスクロールなしに主要操作が収まることを確認しています。

## 音声入力

Web Speech API の `SpeechRecognition` / `webkitSpeechRecognition` を使用します。Chrome系ブラウザ推奨です。音声がブラウザ提供者の認識サービスへ送られる場合があるため、個人情報や機密情報は読み上げないでください。アプリ自身は録音データや認識文章を送信・保存しません。

## ローカル起動

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。音声入力にはHTTPSまたはlocalhostが必要です。
