# ECHO//SEVEN

7回の時間。6人の過去。1つのコア。

スマホ向けのタイムループ・アクションローグライトです。15秒間の移動・射撃・DASHが記録され、次の周回では過去の自分が味方として同じ行動を再生します。

**Play:** https://bachikoljunior-blip.github.io/Gptgame/

## 遊び方

- DASHボタンと反対側をドラッグして移動
- 攻撃は最も近い敵へ自動照準
- DASH中は無敵。移動指と同時に押せます
- 2・4・6周目の後に強化を選択
- 7周目に6体のエコーとSEPTAGONを破壊

タッチ、マウス、キーボード（WASD／矢印、Space）、左利き配置、動きを減らす設定、手続き型サウンド、振動に対応しています。

## データと通信

ゲーム本体は外部ランタイム依存なしの単一HTMLです。設定・ベスト記録・seedだけをブラウザ内に保存し、プレイデータを外部送信しません。

## 開発

Node.js 20以上で、依存パッケージなしの品質ゲートを実行できます。

~~~sh
npm test
~~~
