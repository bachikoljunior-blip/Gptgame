# 声打（こえだ）

声で日本語のお題を読み、制限時間内の速さ・正確さ・コンボを競う、音声入力専用のブラウザゲームです。

## 遊び方

1. 30・60・90秒から制限時間を選びます。
2. 「やさしい・ふつう・むずかしい」から難易度を選びます。
3. 「マイクをオンにして開始」を押し、表示されたお題を読みます。
4. 正しく認識されると次のお題へ進みます。

スコア、文字／分、正確率、最大コンボを集計します。コース別の上位10件はブラウザの `localStorage` に保存されます。サーバーランキングやログイン機能はありません。

## 同音異字・表記ゆれへの対応

音声認識が返す候補を最大5件まで確認し、先頭候補が誤変換でも、別候補が正しければ正解になります。

さらに、お題ごとに登録した同音の表記ゆれも正解として扱います。たとえば「お寿司／お鮨」「精度／制度」「柿／牡蠣」のように、発音は合っているものの変換結果だけが異なるケースを吸収します。

この辞書はお題ごとの限定リストです。意味の異なる文章を無条件に正解へするのではなく、音声認識で起きやすい変換だけを登録しています。

## 聞き取りのリセット

ゲーム中の「聞き取りをリセット」を押すと、現在たまっている認識文字だけを消し、同じお題を最初から読み直せます。

- 得点は変わりません
- コンボは切れません
- お題は変わりません
- ゲーム全体とお題の残り時間はそのまま進みます
- マイク認識を停止して、新しい認識セッションとして再開します

## 音声入力とプライバシー

Web Speech API の `SpeechRecognition` / `webkitSpeechRecognition` を使用します。音声認識はブラウザ、OS、地域、回線に依存するため、Chrome系ブラウザを推奨します。

音声がブラウザ提供者の認識サービスへ送られる場合があります。個人情報や機密情報は読み上げないでください。アプリ自身は録音データや認識文章を保存・送信しません。マイクはゲーム開始時に要求し、ゲーム終了時に停止します。

## ローカル起動

静的ファイル1枚なので、リポジトリのルートをHTTP配信してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。音声入力にはHTTPSまたはlocalhostが必要です。
