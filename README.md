# ECHO//SEVEN

7回の時間。6人の過去。1つのコア。

スマホ向けの一人称3Dタイムループ・アクションローグライトです。15秒間の移動・照準・手動射撃・DASHが記録され、次の周回では過去の自分が立体アリーナ上の味方として同じ行動を再生します。

**Play:** https://bachikoljunior-blip.github.io/Gptgame/

## 遊び方

- FIRE／DASHボタンと反対側を短くドラッグして、視点方向を基準に素早く移動
- アクションボタン側の画面をドラッグして一人称視点を旋回
- FIREを押した時だけ照準方向へ射撃。押したまま左右へ滑らせると、二本指のまま連射と照準を同時操作
- DASHも押したまま左右へ滑らせて照準を維持可能
- DASH中は無敵。移動指と同時に押せます
- 2・4・6周目の後に強化を選択
- 7周目に6体のエコーとともにSEPTAGONを破壊

タッチ、マウス、キーボード（WASD／矢印で移動、Q／Eで旋回、Fで射撃、SpaceでDASH）、左利き配置、動きを減らす設定、手続き型サウンド、振動に対応しています。描画はWebGL 2／WebGL 1を自動選択し、非対応・コンテキスト喪失・描画失敗時はゲームを止めず、照準線付きCanvas 2Dへフォールバックします。

各ランの結果画面には端末診断があります。フレーム安定性、処理時間、最大敵・弾・演出数、自動画質、DPR、移動と手動射撃／DASHの同時操作、停止復帰、音声解放を端末内だけで計測し、診断結果をコピーできます。

## データと通信

ゲーム本体は外部ランタイム依存なしの単一HTMLです。3Dシーン用WebGL CanvasとHUD／フォールバック用Canvasを同じHTML内で重ねています。設定・ベスト記録・seedと進行中ランの一時復元情報をブラウザ内に保存し、プレイデータを外部送信しません。同じタブが再読み込みされた場合は、進行中のランを入力解除済みの一時停止状態で復元します。タイトルへ戻ったランや終了済みランは復元しません。

## 開発

Node.js 20以上で、依存パッケージなしの品質ゲートを実行できます。47件のテストには配信HTMLの内容IDと改変拒否、狭い画面で横スクロールしないタイトル階層、モバイル向け情報階層とWebGL／Canvas双方の視覚要素、二本指での移動＋FIRE照準、端末幅に依存しない視点感度、短い親指移動への反応、手動射撃の無入力保証・連射間隔・照準記録再生、4方向のカメラ／照準／弾道一致、コア侵入防止、実ポインター処理、自動画質変更時の入力保持、左利き表示、旧セーブ移行、同一タブ再読み込みからの戦闘・終盤・強化選択復元、壊れた一時保存の破棄、WebGL 1／2、ストレス時の三角形上限、バッファ再利用、コンテキスト復旧、Canvas/WebGL間の6,300tickゴールデントレースが含まれます。
